# SI8 Customer Submission Checklist
**Version:** 0.1 · July 2026
**Purpose:** Standalone reference — share via email, Google Doc, Notion, or paste into CertForm instructions
**Note:** This is a condensed evidence reference. See the SI8 Evidence Preparation Guide for full descriptions of each category.

---

## How to Use This Checklist

Work through each category and gather what you have. Items marked **Important** have the greatest impact on commercial confidence and should be prioritised. Items marked **Conditional** apply only when the condition is met. Items marked **Optional** are helpful but not required.

If something is missing, note that in your submission — SI8 documents evidence gaps as part of the assessment.

---

## Final Content

| Item | Priority | Notes |
|------|----------|-------|
| Video file or streaming link (final deliverable, highest quality available) | **Important** | All versions intended for commercial use |
| Campaign brief or description of intended commercial use | **Important** | Advertising, broadcast, social, OOH, etc. |
| Countries or regions where content will be deployed | **Important** | Affects jurisdiction-specific risk assessment |
| Platforms where content will appear | Helpful | YouTube, Meta Ads, broadcast, etc. |
| Approximate campaign start date | Helpful | |

---

## AI Tools and Platforms

| Item | Priority | Notes |
|------|----------|-------|
| Names of all AI tools used in production | **Important** | Video generation, audio, voice, upscaling, editing |
| Generation model or version (e.g., Runway Gen-3 Alpha, Kling 1.6) | Helpful | Include if known |
| Sequence of tools used (if multiple) | Helpful | Brief description of workflow order |

---

## Commercial License Evidence

*This is the most commonly missing category. Gather this before submitting.*

| Item | Priority | Notes |
|------|----------|-------|
| Subscription receipt or invoice for each AI tool used | **Important** | Confirms paid plan at time of generation |
| Account screenshot showing active paid plan (if no receipt available) | **Important** | Alternative to receipt |
| Commercial license terms for each tool (link or screenshot) | Helpful | Confirms commercial output rights |
| For custom or fine-tuned models: documentation of training data source and rights | Conditional | Required if custom model or LoRA used |

---

## Human Creative Contribution

| Item | Priority | Notes |
|------|----------|-------|
| Brief workflow description | **Important** | Who directed, what was prompted, what was edited — one paragraph is sufficient |
| Prompt log or generation notes (if preserved) | Helpful | Not required — include if available |
| Editing or post-production description | Helpful | What changes were made to AI output before final delivery |
| Project file or editing timeline export | Optional | |

---

## Third-Party Assets

| Item | Priority | Notes |
|------|----------|-------|
| List of any stock footage, images, or graphics incorporated | Conditional | Required if third-party assets were used |
| License documentation for each stock asset | Conditional | Required if third-party assets were used |

---

## Music, Audio, and Sound

| Item | Priority | Notes |
|------|----------|-------|
| Identification of all audio in the content (music, voice, sound effects) | **Important** | State source for each: AI-generated / licensed / original recording |
| For licensed music: sync license and master license | Conditional | Required if licensed music is used |
| For AI-generated audio: tool name and commercial license receipt | Conditional | Required if AI audio tool was used |
| For original recordings: confirmation that creator holds all rights | Conditional | Required if original recordings are used |

---

## Likeness, Voice, and Performer Rights

| Item | Priority | Notes |
|------|----------|-------|
| Statement confirming whether any real person appears in the content (face, voice, persona) | **Important** | Include even if no real person appears — it helps the reviewer |
| Signed talent release or right of publicity license | Conditional | Required if a real person's likeness or voice is included |
| Consent documentation for any named individual depicted | Conditional | Required if a specific person is referenced or depicted |
| Confirmation that AI-generated performers are not based on a specific real person | Helpful | |
