# Formal Governance Reviews — Archive

Verbatim archive of Formal Governance Review reports for candidate Living Knowledge claims. `GOVERNED-CLAIMS.md` remains the canonical current-state ledger and carries only a condensed review summary per adopted claim; the full decision-analysis record — clause-by-clause accuracy tests, source-tier assessments, atomicity/boundary tests, the complete numbered report — lives here.

**Process requirement:** see `GOVERNED-CLAIMS.md`'s own governance-discipline section (top of file) for the rule requiring every Formal Governance Review to be preserved this way.

## Naming convention

`FGR_NNN_<reviewed-object-id>_<review-date>.md` — sequence number, the exact candidate ID under review, and the review date.

## Verbatim discipline

Each file wraps the original report in a minimal metadata header (title, reviewed object, date, artifact type, historical status, PM adoption status, reconstruction source) plus a `--- BEGIN VERBATIM GOVERNANCE REVIEW ---` / `--- END VERBATIM GOVERNANCE REVIEW ---` boundary. **Nothing inside that boundary is ever edited after the fact** — not to fix a later-discovered inconsistency, not to reflect a subsequent PM decision, not to harmonize terminology with a later review. A superseded or corrected analysis gets a new review artifact, never a rewritten old one. Only the wrapper metadata outside the boundary (specifically: PM adoption status) is ever updated as later events occur.
