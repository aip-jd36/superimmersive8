# Living Notebook

Four flat markdown files. No database, no tooling beyond `Read`/`grep`. Spec: `08_Platform/prds/PRD_LIVING_NOTEBOOK.md` — read that first if you're adding an entry for the first time; this file is just the index.

| File | What goes in it |
|---|---|
| [`PLATFORM-RIGHTS-MATRIX.md`](PLATFORM-RIGHTS-MATRIX.md) | Per-AI-tool facts about commercial rights, training data disclosure, known restrictions |
| [`SI8-POSITIONS.md`](SI8-POSITIONS.md) | Settled stances SI8 has taken and is prepared to repeat consistently |
| [`EDGE-CASES.md`](EDGE-CASES.md) | Resolved judgment calls, one per case, not yet (or not ever) general enough to be a Position |
| [`PENDING-QUESTIONS.md`](PENDING-QUESTIONS.md) | Open questions that materially affect consistency, with a stated promotion path |

## Before you add an entry

- It should exist because something happened (an assessment, a conversation, a platform change) — not because it seemed worth writing down in the abstract.
- Cite the source. Every entry format below has a source/date field — fill it in, even informally.
- If you're not sure whether something is a Position or an Edge Case: a Position is something SI8 would say the same way in two different conversations without checking notes first. An Edge Case is a specific judgment call that might not generalize yet. When in doubt, log it as an Edge Case — promotion to Position happens deliberately (see the PRD's Promotion Rules), not by default.
- Cross-link with `[[POS-NNN]]`, `[[EC-NNN]]`, `[[PQ-NNN]]` when entries relate to each other.
