# CR-DESIGN-2B — Implementation acceptance criteria

**Status: PROPOSED — NOT APPROVED.** CR-DESIGN-2B is not authorised by this document. When authorised, it is a local, inert implementation: v6/v7 stay `pending`, the generator stays `creator-record-v2-pdf-v3` in Production, and there is no deployment or cutover.

## 1. Scope boundary (must all hold)

- New presentation code and the presentation configuration (`04-PRESENTATION-IDENTITY-AND-VERSIONING.md`) only. The v4/v5 render path is unchanged and still selected for legacy sets.
- v6/v7 template proposals registered as **pending**, never approved in code; only approved v4/v5 can render outside tests.
- No change to: record builder, schemas, questionnaire, Source Text, ledger or registry, Living Knowledge, guidance selection, examination pipeline, eligibility, checkout, issuance, consent, Terms, AI permission, migrations.
- Fonts: static Fraunces, Inter and IBM Plex Mono (OFL 1.1) files in `customer-pdf/fonts/` with licence files and pinned SHA-256; Noto Sans CJK TC kept as fallback.
- Every string comes from the template set or the record. The only renderer-originated characters are page numbers and bullet marks, as today.
- No "8" mark; A4; no printed page cross-references; no tagged PDF.

## 3. Automated tests (all must pass)

**Guidance completeness**
- Every governed explanation, caveat, conclusion, framing and boundary string in the model appears once, complete, in the extracted PDF text.
- No string ends in "…" or contains "continues on page".

**Caveat association**
- Each caveat panel appears once, with its "Applies to considerations N" row.
- Placement follows contract C5.
- No caveat text appears twice.
- `consolidated[]` equals the v4/v5 layout's for the same input.

**D10**
- No block derived from a document is in the guidance section, overview map or caveat panel.
- Every reading appears only in section 6, in the reading register.
- No reading row shares a row or box with a declaration.
- The `readiness_layout_refused` guards still fire: integrated assessment, and comparison method ≠ v2.

**Exactly once and order**
- The printed block multiset and order equal the v4/v5 tree for identical strings.
- `checked()` invariants hold.

**Disclosures**
- The full `t.stamp` and `t.footer` text appear on **every** page (extracted text per page) and the full stamp appears prominently on page 1.
- Measured text size is at least the v5 size (stamp 7.5 pt, footer 7 pt), and contrast is at least 4.5:1 for both.

**Pagination**
- Page count equals "of M" on every page.
- No heading is the last element on a page.
- No consideration head is separated from its conclusion and first explanation lines.
- No `open` box sits on a page without its explanation.
- No label is separated from its value.
- Long values wrap with no characters lost: extracted text equals model text, ignoring line breaks.

**Font coverage**
- The glyph check covers every family in each stack.
- `text_unsupported` refusal is preserved.
- Pinned font hashes match.
- Fonts are present in `outputFileTracingIncludes` for every issuing route.

**Label supersets**
- Every closed label map in v6/v7 ⊇ v4/v5, so no previously renderable record becomes `templates_unavailable`.

**Wording**
- v6/v7 pass the wording lock.
- Every v6/v7 string is either identical to a v4/v5 string at the same path or listed in an approved addition table.
- A test prints the diff.

**Presentation identity**
- A tampered presentation configuration refuses (`presentation_mismatch`).
- A template whose presentation contract is not implemented refuses.

**Historical preservation**
- v1–v5 still render with today's code for existing fixtures (structural snapshot unchanged).
- No code path re-renders an issued artifact.
- The generator ownership, takeover-guard and rollback-guard static tests pass, with `v4` added only behind a not-yet-approved flag.

**Regression**
- Full suite: failing set equal to the 24-suite / 89-test baseline.
- `tsc` clean; `next build` exit 0; customer-wording check exit 0.

## 4. Visual review (actual output)

- Rasterise P1–P13 (e.g. `pdftoppm` at 150 dpi) and review the **generated PDFs and images**, not the design HTML.
- Check in colour and in grayscale: three registers distinguishable; the guidance is the clear hero; disclosures readable; no orphaned blocks; long and international strings intact.
- Print one copy of P4 and P11 on an office printer at 100% scale (A4) and confirm the running stamp and footer are legible.
- PM/Architecture records acceptance per PDF. Design feedback is recorded as presentation-configuration changes only, never as wording edits.

## 5. Release preconditions (for CR-DESIGN-2C, not 2B)

- Founder approval of v6/v7, the presentation contract and the decisions in `06-FOUNDER-DECISION-SHEET.md`.
- LK-G classification of any approved new strings.
- Drain gate: paid-not-completed = 0 and no pending v3 rows; guarded cutover; Production UAT with one operator purchase (preferably a fresh reading); confirm earlier artifacts unchanged.
