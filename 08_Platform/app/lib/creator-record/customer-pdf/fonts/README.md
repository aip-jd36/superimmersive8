# Customer PDF fallback font

`NotoSansCJKtc-Regular.otf` is the unmodified Noto Sans CJK TC Regular, version 2.004, from https://github.com/notofonts/noto-cjk (tag `Sans2.004`, `Sans/OTF/TraditionalChinese/`). Licensed under the SIL Open Font License 1.1: see `LICENSE`.

SHA-256: `dce08bd4fd91aa8aa76ed8fea4b694c2dfb8550f67871e326843212ddbeb88b4` (test-pinned).

It prints only characters Helvetica does not hold. It covers Traditional and Simplified Chinese, Vietnamese, kana and Hangul. It has no bold weight, so these characters print in regular weight inside headings and labels. It has no emoji.
