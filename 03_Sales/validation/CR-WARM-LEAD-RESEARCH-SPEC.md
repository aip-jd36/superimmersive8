# CR Warm-Lead Research Spec

**Status:** Working doc, updated per outreach cycle.
**Scope:** High-information warm leads for the Commercial Readiness validation initiative. **Informs both CR-Track A (B2B Readiness) and CR-Track B (Creator Readiness) — not gated to Track A.** Classification happens per-conversation.
**Parent:** `01_Business/product-discovery/COMMERCIAL-READINESS-VALIDATION-PLAN-v1.md`
**Source data:** `03_Sales/CRM.md` (B-IDs, canonical pipeline), `03_Sales/crm/` (crm-core graduated records), `03_Sales/reply-drafts/`, `03_Sales/outreach/SPLIT-TEST-LOG.md`, `03_Sales/campaign-reports/*.md` (verbatim transcripts), `03_Sales/DISCOVERY-PIPELINE.md`.

All 16 candidates below are verified real leads with prior signal already on file — none invented. Two data conflicts are flagged inline and must be resolved before outreach to the affected candidate.

**Research objective — corrected 2026-08-30 (PMM): separate by track, do not impose Track A's prerequisite on Track B conversations.**

- **For Track A-relevant conversations** (candidate already has a documented/structured production process — see `track_a_maturity_basis` in each entry below): understand what happens **after** production state/evidence already exists. Core probe: *"Once you have all that documentation, what happens next before the work can actually go live? Does someone review/sign off on it, or is the documentation itself enough?"* This must stay open to a negative answer — "nothing, the documentation is enough" is valid and important evidence, not a failed probe.
- **For Track B-relevant conversations** (candidate is a hands-on creator without an established documentation practice): understand how they determine commercial readiness **regardless of whether formal documentation exists**. Core probe: *"How do you figure out whether this project is actually okay for its intended commercial use?"* If they raise provenance/prompt-logging pain, acknowledge it but redirect: *"Assume you had all of that information available — would you know whether the project was commercially okay to use?"* Do not treat provenance/documentation pain as validation of the Track B hypothesis; the test concerns the readiness *determination*, not the record-keeping.
- Most candidates below are Track A-relevant (documented process already evidenced); track assignment is called out per-entry.

**Reply-draft disposition (Strategic OS decisions, 2026-08-30 — confirmed for all four):** existing unsent drafts for Ibrahim Badi, Ramez Tabshi, Ivan Petruzzelli, **and Dan Lantry** are **not** sent as-is and are **not** auto-superseded either — they are preserved as historical artifacts, and new personalized follow-ups are prepared referencing each lead's complete prior conversation plus the new Commercial Readiness probe.
